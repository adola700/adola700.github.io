Introducing Jev-Omni

Text, images, audio, and video. One interface for making decisions.

Akhila Datta DolaPublished 26 September 2026

Jev-Omni takes a situation, a question, and a set of options, then returns a probability for each option. It supports text, images, audio, and video.

A model for bounded decisions

The output is a distribution over the choices you provide. This makes it useful when an application needs to choose between defined actions. The model produces its decision in one forward pass, without generating a text response.

Explore the release

The model card contains the architecture, current benchmark results, setup instructions, and limitations. The weights and reference code are available on Hugging Face, along with an interactive demo.
